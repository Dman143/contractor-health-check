# Contractor Health Check

Version 1 of a responsive React, TypeScript, and Tailwind CSS web application that helps small to medium contractors assess the health of their business.

## Features

- Premium landing page with a clear Start Assessment call to action
- 25-question assessment across eight contractor business categories
- One-question-per-screen flow with 1–5 scoring and a progress bar
- Business Health Score out of 100
- Professional results page with category scores, top strengths, top opportunities, a recommended next step, and a Book a Strategy Call button

## Preview Locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually <http://localhost:5173/>.

## Production Build

```bash
npm run build
npm run preview
```
